## 2. 핵심 API 흐름

### 2.1 주소 검색 → 필지 정보 조회

```
사용자 입력: "강남구 역삼동 123-4"
       │
       ▼
[1] 브이월드 Geocoding API
    GET https://api.vworld.kr/req/search
    → 좌표(x, y), PNU 코드 반환
       │
       ▼
[2] 국가공간정보포털 토지특성정보 API
    → 대지면적, 지목, 용도지역, 용도지구
       │
       ▼
[3] 토지이용규제정보서비스 API
    → 용도지역/용도지구 상세, 지구단위계획 여부
       │
       ▼
[4] 세움터 건축행정시스템 API
    → 인접도로 정보, 기존 건축물 현황
       │
       ▼
반환: 완성된 LOT 객체
```

### 2.2 AI 규모검토 (Claude API)

```
입력: LOT 객체 + 건물 용도 + 사용자 요구사항
       │
       ▼
[1] 법규 DB에서 해당 용도지역·지자체 규제 조회
    → 건축법, 시행령, 해당 지자체 조례 텍스트
       │
       ▼
[2] Claude API 호출 (Structured Output)
    System: "대한민국 건축법규 전문가. 아래 법규를 근거로 분석."
    User: {
      lot: { 면적, 용도지역, 도로폭, ... },
      use: "다세대주택",
      regulations: { 건축법 관련 조항들, 지자체 조례 },

       │
       ▼

    {
      "summary": { 건축면적, 연면적, 층수, 높이, ... },
      "regulations": [
        { "law": "건축법 제61조",
          "check": "일조권",
          "status": "pass",
          "detail": "..." ,
          "reasoning": "..." }
      ],
      "building_mass": { 가로, 세로, 층별높이[], ... },
      "parking": { 법정대수, 산출근거 },
      "setbacks": { 전면, 후면, 측면 },
      "warnings": ["지구단위계획 확인 필요"],
```

## 3. 법규 데이터베이스 설계

### 3.1 테이블 구조

```sql
-- 법률 원문
CREATE TABLE regulations (
  id SERIAL PRIMARY KEY,
  law_name VARCHAR(100),        -- '건축법', '국토계획법', ...
  article VARCHAR(20),          -- '제61조'
  clause VARCHAR(20),           -- '제1항'
  title TEXT,                   -- '일조 등의 확보를 위한 건축물의 높이 제한'
  content TEXT,                 -- 조문 전문
  effective_date DATE,
  last_updated TIMESTAMP,
  category VARCHAR(50)          -- 'height', 'coverage', 'far', 'parking', ...
);

-- 지자체 조례
CREATE TABLE local_ordinances (
  id SERIAL PRIMARY KEY,
  region_code VARCHAR(10),      -- 행정구역 코드
  region_name VARCHAR(50),      -- '서울특별시', '강남구'
  ordinance_name VARCHAR(200),
  article VARCHAR(20),
  content TEXT,
  zone_type VARCHAR(50),        -- 용도지역
  coverage_rate DECIMAL(5,2),   -- 건폐율
  floor_area_rate DECIMAL(7,2), -- 용적률
  height_limit DECIMAL(6,1),    -- 높이제한
  effective_date DATE,
  last_updated TIMESTAMP
);

-- 용도지역별 규제 요약 (빠른 조회용)
CREATE TABLE zone_regulations (
  id SERIAL PRIMARY KEY,
  region_code VARCHAR(10),
  zone_type VARCHAR(50),        -- '제2종일반주거지역'
  max_coverage DECIMAL(5,2),
  max_far DECIMAL(7,2),
  max_height DECIMAL(6,1),
  sunlight_required BOOLEAN,
  min_road_width DECIMAL(4,1),
  front_setback DECIMAL(4,1),
  side_setback DECIMAL(4,1),
  rear_setback DECIMAL(4,1),
  parking_standard JSONB,       -- 용도별 주차 기준
  landscaping_rate DECIMAL(5,2),
  source_articles TEXT[]         -- 근거 조문 목록
);

-- 분석 이력
CREATE TABLE analysis_history (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID,
  lot_data JSONB,
  building_use VARCHAR(50),
  claude_response JSONB,
  visualization_params JSONB,
  created_at TIMESTAMP DEFAULT now(),
  pdf_url TEXT
);
```

## 4. Claude API 연동 상세

### 4.1 System Prompt 구조

```
당신은 대한민국 건축법규 전문가입니다.

[역할]
주어진 토지 정보와 건물 용도를 기반으로 신축 가능한 최대 건축 규모를 산출합니다.

[적용 법규]
1. 건축법 — 건폐율(제55조), 용적률(제56조), 높이제한(제60조), 
   일조권(제61조), 대지안의공지(제58조)
2. 국토의 계획 및 이용에 관한 법률 — 용도지역별 건폐율(제77조), 
   용적률(제78조)
3. 주차장법 시행령 — 부설주차장(제6조)
4. {해당 지자체} 건축조례 — {관련 조문 동적 삽입}

[산출 공식]
- 건축면적 = 대지면적 × 건폐율
- 연면적 = 대지면적 × 용적률
- 최대 층수 = min(높이제한/층고, 연면적/건축면적)
- 도로사선 높이 = 전면도로폭 × 1.5
- 일조권 높이 = 9m + (도로폭/2 × 0.5) + (대지면적 > 200㎡ ? 3m : 0)
- 주차 = ceil(연면적 / 용도별 기준면적)
- 이격거리 = 용도지역별 전면/측면/후면 기준

[출력 형식]
반드시 아래 JSON 스키마에 맞춰 응답하세요.
{schema}

[주의사항]
- 불확실한 경우 warnings에 명시
- 지구단위계획 구역은 별도 기준 적용 가능성 안내
- 모든 판정에 근거 법조문을 sources에 포함
- confidence는 0~1 (0.9 이상: 높은 신뢰도)
```

### 4.2 API 호출 코드 (Next.js)

```typescript
// /api/analyze/route.ts
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic();

export async function POST(req: Request) {
  const { lot, buildingUse } = await req.json();
  
  // 1. 해당 지자체 법규 조회
  const regulations = await getRegulations(lot.regionCode, lot.zoneType);
  
  // 2. System Prompt 조립
  const systemPrompt = buildSystemPrompt(regulations);
  
  // 3. Claude API 호출
  const response = await client.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 4096,
    system: systemPrompt,
    messages: [{
      role: "user",
      content: JSON.stringify({
        task: "신축 최대 규모 산출",
        lot: {
          address: lot.address,
          area: lot.area,
          zoneType: lot.zoneType,
          landUse: lot.landUse,
          roadWidth: lot.roadWidth,
          shape: lot.shape,
          slope: lot.slope,
          direction: lot.direction,
          districtPlan: lot.districtPlan
        },
        buildingUse: buildingUse,
        regulations: regulations.summary
      })
    }],
    // Structured Output (Tool Use로 스키마 강제)
    tools: [{
      name: "building_feasibility_result",
      description: "신축규모검토 결과",
      input_schema: RESULT_SCHEMA
    }],
    tool_choice: { type: "tool", name: "building_feasibility_result" }
  });
  
  // 4. 결과 파싱
  const result = response.content[0].input;
  
  // 5. 이력 저장
  await saveAnalysis(lot, buildingUse, result);
  
  return Response.json(result);
}
```

### 4.3 응답 JSON 스키마

```typescript
const RESULT_SCHEMA = {
  type: "object",
  properties: {
    summary: {
      type: "object",
      properties: {

        buildingArea: { type: "number", description: "건축면적(㎡)" },
        totalFloorArea: { type: "number", description: "연면적(㎡)" },
        coverageRatio: { type: "number", description: "건폐율(%)" },
        floorAreaRatio: { type: "number", description: "용적률(%)" },
        floors: { type: "integer", description: "지상 층수" },
        basementFloors: { type: "integer", description: "지하 층수" },
        buildingHeight: { type: "number", description: "건물높이(m)" },
        maxHeight: { type: "number", description: "법정 최고높이(m)" }
      },
      required: ["siteArea","buildingArea","totalFloorArea","coverageRatio",
                  "floorAreaRatio","floors","buildingHeight"]
    },
    regulations: {
      type: "array",
      items: {
        type: "object",
        properties: {
          law: { type: "string" },
          check: { type: "string" },

          reasoning: { type: "string" }
        }
      }
    },
    buildingMass: {
      type: "object",
      properties: {
        width: { type: "number" },
        depth: { type: "number" },

          type: "object",

        }
      }
    },
    parking: {
      type: "object",
      properties: {
        required: { type: "integer" },
        area: { type: "number" },
        basis: { type: "string" }

    },
    landscaping: {
      type: "object",
      properties: {
        required: { type: "number" },
        ratio: { type: "number" },
        basis: { type: "string" }

    },
    warnings: { type: "array", items: { type: "string" } },
    confidence: { type: "number" },
    sources: { type: "array", items: { type: "string" } },
    aiAnalysis: { type: "string", description: "AI 종합 분석 의견" }
  },
  required: ["summary","regulations","buildingMass","parking","confidence","sources"]
```
