## 1. 서비스 정의

### 1.1 한 줄 정의

> **신축규모검토 v2.0**은 Claude API 기반 AI가 대한민국 건축 관련 법규(건축법, 국토계획법, 주차장법, 광역·기초 자치단체 조례 등)를 실시간 분석하여 특정 필지의 신축 가능 규모(건폐율, 용적률, 높이, 세대 수, 주차 대수 등)를 자동 산출하고, 3D 매스 시각화와 PDF 보고서를 제공하는 AI 건축 타당성 분석 플랫폼이다.

### 1.2 서비스 유형

| 항목 | 내용 |
|------|------|
| 서비스 유형 | 반응형 웹 애플리케이션 + 네이티브 앱(iOS/Android) |
| 수익 모델 | 프리미엄 구독(월/연), 건별 분석 과금, 럭셔리앤 인테리어 상담 연결(CTA) |
| AI 엔진 | Anthropic Claude API (claude-sonnet-4-20250514 이상) |
| 외부 API | 브이월드(V-World) 공간정보 API, 국토교통부 건축행정시스템(세움터), 법제처 국가법령정보센터 API |
| 브랜드 | LUXURYN INTERIOR 로고 및 디자인 시스템 적용 |

### 1.3 핵심 가치 제안

1. **즉시성**: 전문 건축사 검토 대비 수일~수주 소요되는 규모검토를 5분 이내로 단축
2. **정확성**: 233조 건축법, 119조 건축법 시행령, 142조 국토계획법, 30조 주차장법 + 17개 광역·226개 기초 자치단체 조례를 교차 검증
3. **시각성**: 3D 매스 모델과 게이지 차트로 직관적 결과 제공
4. **연결성**: 분석 결과에서 럭셔리앤 인테리어 전문 상담으로 자연스러운 전환

## 2. 프로젝트 배경 및 목표

### 2.1 배경

- 럭셔리앤 분양대행 현장에서 시행사·건축주가 규모검토를 의뢰하면 외부 건축사사무소에 용역을 주어 최소 3~5일, 비용 200~500만원이 소요됨
- 기존 v1.0(단순 건폐율·용적률 계산기)은 조례 미반영, 주차장·일조·높이 제한 미적용으로 실무 활용도가 낮았음
- Claude API의 긴 컨텍스트 윈도우(200K 토큰)를 활용하면 수백 개 법조문을 한 번에 투입하여 교차 분석이 가능

### 2.2 정량 목표

| 지표 | 목표 | 기간 |
|------|------|------|
| 월간 분석 건수 | 5,000건 | Phase 2 완료 후 6개월 |
| 평균 분석 소요 시간 | 90초 이내 | Phase 1 런칭 시 |
| AI 분석 정확도 | 건축사 검토 결과 대비 95% 이상 일치 | Phase 2 완료 시 |
| 럭셔리앤 인테리어 상담 전환율 | 분석 완료 사용자의 8% 이상 | Phase 1 런칭 후 3개월 |
| 유료 전환율 | MAU의 5% 이상 | Phase 2 완료 후 6개월 |

### 2.3 성공 기준

- 럭셔리앤 내부 분양대행팀(영업직원 50명 이상)이 현장에서 태블릿으로 즉시 규모검토 시연 가능
- 시행사·건축주가 초기 사업성 판단에 본 서비스 결과물을 실제 활용
- 럭셔리앤 인테리어 상담 문의가 CTA를 통해 월 400건 이상 유입

### 4.2 기능 상세: F03 AI 법규 분석

AI 법규 분석은 본 서비스의 핵심 기능으로, 다음과 같은 파이프라인으로 동작한다.

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI 법규 분석 파이프라인                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 필지 정보 수집 (V-World API)                                │
│     └─ 지목, 면적, 용도지역·지구·구역, 접도 현황                  │
│                                                                 │
│  2. 적용 법규 선별                                              │
│     ├─ 건축법 + 시행령 (전국 공통)                                │
│     ├─ 국토계획법 + 시행령 (용도지역별 적용)                      │
│     ├─ 주차장법 + 시행령 (용도별 주차 기준)                       │
│     └─ 해당 자치단체 조례 (시·군·구 특정)                         │
│                                                                 │
│  3. Claude API 호출 (Streaming)                                 │
│     ├─ System Prompt: 건축법규 전문가 역할 정의                   │
│     ├─ Context: 필지 정보 + 적용 법규 조문 전문                   │
│     └─ User Prompt: 분석 요청 (구조화된 JSON 출력 요구)           │
│                                                                 │
│  4. 응답 파싱 및 검증                                            │
│     ├─ JSON Schema 검증                                         │
│     ├─ 수치 범위 검증 (건폐율 0~100%, 용적률 0~1500% 등)         │
│     └─ 법조문 인용 검증 (조문 번호 존재 여부)                     │
│                                                                 │
```

#### Claude API 호출 사양

| 항목 | 값 |
|------|-----|
| 모델 | `claude-sonnet-4-20250514` (Phase 1), `claude-opus-4-20250514` (Phase 2 고급 분석) |
| Max Tokens | 8,192 (결과 JSON) |
| Temperature | 0.1 (사실 기반 분석이므로 낮게 설정) |
| System Prompt 길이 | 약 15,000 토큰 (법규 전문가 역할 + 출력 JSON 스키마) |
| Context 길이 | 약 50,000~120,000 토큰 (필지 정보 + 적용 법규 조문) |
| Streaming | 활성화 (사용자에게 실시간 분석 과정 표시) |
| Structured Output | JSON Mode 사용, 응답 스키마 사전 정의 |

## 11. 비기능 요구사항

### 11.1 성능

| 항목 | 기준 |
|------|------|
| 주소 검색 자동완성 응답 | 200ms 이내 |
| 필지 정보 조회 | 1초 이내 |
| AI 분석 첫 토큰 응답 (TTFT) | 2초 이내 |
| AI 분석 전체 완료 | 90초 이내 |
| 페이지 초기 로딩 (LCP) | 2.5초 이내 |
| 3D 뷰어 렌더링 | 60fps 이상 (데스크톱), 30fps 이상 (모바일) |
| PDF 생성 | 10초 이내 |

### 11.2 보안

- HTTPS 필수 (TLS 1.3)
- Claude API 키 서버 측에서만 사용 (클라이언트 노출 금지)
- 개인정보(이름, 연락처) AES-256 암호화 저장
- OWASP Top 10 대응
- 개인정보처리방침 및 이용약관 게시
- GDPR 불필요 (국내 서비스), 개인정보보호법 준수

### 11.3 접근성

- WCAG 2.1 AA 수준 준수
- 키보드 네비게이션 완전 지원
- 스크린 리더 호환 (aria-label, role 속성)
- 색상 대비 비율 4.5:1 이상
- 모바일 터치 타겟 최소 44px

### 11.4 가용성

- 서비스 가용률 99.5% 이상 (월간)
- Claude API 장애 시 "일시적 서비스 불가" 안내 + 재시도 큐
- 데이터 백업 일 1회, 7일 보관

## 13. 용어 정의

| 용어 | 정의 |
|------|------|
| **건폐율** | 대지 면적에 대한 건축 면적(건물이 땅을 덮는 면적)의 비율 (%) |
| **용적률** | 대지 면적에 대한 건축물의 연면적(지상 각 층 바닥 면적의 합계)의 비율 (%) |
| **일조권 사선 제한** | 인접 대지의 일조를 확보하기 위해 건축물의 높이를 제한하는 규정 |
| **도로사선 제한** | 전면 도로 폭에 비례하여 건축물의 높이를 제한하는 규정 |
| **대지 안의 공지** | 건축물과 대지 경계선 사이에 확보해야 하는 최소 이격 거리 |
| **부설주차장** | 건축물의 용도와 규모에 따라 건축물 내 또는 그 부지에 의무적으로 설치해야 하는 주차장 |
| **건축선** | 도로와 접하는 부분에서 건축물을 건축할 수 있는 선 |
| **가로구역** | 도로로 둘러싸인 일단의 지역 |
| **브이월드(V-World)** | 국토교통부가 운영하는 공간정보 오픈 플랫폼 (vworld.kr) |
| **세움터** | 국토교통부 건축행정시스템. 건축 인허가 정보 조회 가능 |
| **PNU** | 필지고유번호 (Parcel Number Unique). 19자리 숫자로 전국 필지를 고유 식별 |
| **FAR** | Floor Area Ratio. 용적률의 영문 약어 |
| **BCR** | Building Coverage Ratio. 건폐율의 영문 약어 |
