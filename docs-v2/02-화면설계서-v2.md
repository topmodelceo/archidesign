## 1. 디자인 시스템

### 1.1 색상 토큰 (CSS Custom Properties)

럭셔리앤 인테리어 브랜드 디자인 시스템을 기반으로 한다.

```css
:root {
  /* ── 배경 ── */
  --bg:        #FAF9F7;    /* 페이지 배경. 따뜻한 오프화이트 */
  --card:      #FFFFFF;    /* 카드, 모달, 패널 배경 */
  --bar:       #F6F2ED;    /* 상단 바, 탭 바, 섹션 구분 배경 */
  --line:      #ECE6DE;    /* 구분선, 보더 */

  /* ── 브랜드 ── */
  --gold:      #A8834F;    /* 기본 골드. CTA, 주요 액션, 로고 */
  --gold-lt:   #C4A57A;    /* 라이트 골드. 호버, 보조 강조 */
  --gold-bg:   #F5EDE3;    /* 골드 배경 틴트. CTA 카드 배경 */
  --gold-10:   rgba(168, 131, 79, 0.10);  /* 골드 10% 오버레이 */

  /* ── 텍스트 ── */
  --ink:       #2F2E2C;    /* 최강조 텍스트. 제목, 핵심 수치 */
  --text:      #3B3A38;    /* 본문 텍스트 */
  --muted:     #8A8783;    /* 보조 텍스트, 레이블, 캡션 */
  --disabled:  #C5C2BD;    /* 비활성 텍스트, 아이콘 */

  /* ── 다크 ── */
  --dark:      #2B2926;    /* 다크 배경 (다크 모드 시) */
  --dark-card: #3A3835;    /* 다크 모드 카드 배경 */
  --dark-line: #4A4744;    /* 다크 모드 보더 */

  /* ── 상태 ── */
  --pass:      #5B8C5A;    /* 적합, 성공, 안전 (그린) */
  --pass-bg:   #EDF5ED;    /* 적합 배경 */
  --warn:      #C4923E;    /* 주의, 경고 (앰버) */
  --warn-bg:   #FDF5E9;    /* 주의 배경 */
  --fail:      #B55454;    /* 부적합, 오류 (레드) */
  --fail-bg:   #FCEEED;    /* 부적합 배경 */
  --info:      #5A7EA8;    /* 정보, 안내 (블루) */
  --info-bg:   #EDF2F8;    /* 정보 배경 */

  /* ── 게이지 ── */
  --gauge-safe:    #5B8C5A;  /* 0~70% 구간 (안전) */
  --gauge-caution: #C4923E;  /* 70~90% 구간 (주의) */
  --gauge-danger:  #B55454;  /* 90~100% 구간 (위험) */
  --gauge-track:   #ECE6DE;  /* 게이지 트랙 (미충족) */

  /* ── 그림자 ── */
  --shadow-sm:  0 1px 2px rgba(43, 41, 38, 0.06);
  --shadow-md:  0 4px 12px rgba(43, 41, 38, 0.08);
  --shadow-lg:  0 8px 24px rgba(43, 41, 38, 0.12);
  --shadow-xl:  0 16px 48px rgba(43, 41, 38, 0.16);

  /* ── 레이아웃 ── */
  --radius-sm:  6px;
  --radius-md:  10px;
  --radius-lg:  16px;
  --radius-xl:  24px;
  --radius-full: 9999px;

  --gutter:     16px;      /* 모바일 좌우 여백 */
  --max-width:  960px;     /* 데스크톱 콘텐츠 최대 폭 */
}
```

### 1.4 아이콘 시스템

- **아이콘 라이브러리**: Lucide Icons (라인 스타일, 1.5px 두께)
- **크기 체계**: 16px (인라인), 20px (버튼·리스트), 24px (네비게이션), 32px (빈 상태), 48px (특수)
- **색상**: 기본 `var(--muted)`, 활성 `var(--gold)`, 상태별 `var(--pass)`, `var(--warn)`, `var(--fail)`

### 1.5 간격 체계 (Spacing Scale)

```
4px  ─── 2xs  (아이콘과 레이블 사이)
8px  ─── xs   (관련 요소 간 최소 간격)
12px ─── sm   (카드 내부 요소 간)
16px ─── md   (기본 간격, 모바일 좌우 여백)
20px ─── lg   (섹션 내부 여백)
24px ─── xl   (카드 패딩)
32px ─── 2xl  (섹션 간 간격)
48px ─── 3xl  (주요 섹션 분리)
64px ─── 4xl  (히어로 영역 상하 여백)
```

### 2.2 컬럼 그리드

```css
.grid-container {
  display: grid;
  gap: 16px;
}

/* Desktop: 12-column grid */
@media (min-width: 1024px) {
  .grid-container {
    max-width: 960px;
    margin: 0 auto;
    grid-template-columns: repeat(12, 1fr);
    gap: 20px;
  }
}

/* Tablet: 8-column grid */
@media (min-width: 768px) and (max-width: 1023px) {
  .grid-container {
    padding: 0 24px;

    gap: 16px;
  }

/* Mobile: 4-column grid */
@media (max-width: 767px) {
  .grid-container {
    padding: 0 16px;

  }
}
```

### 9.2 스트리밍 애니메이션 사양

| 요소 | 애니메이션 | 지속 시간 | 이징 |
|------|----------|----------|------|
| 스트리밍 텍스트 | 타이핑 효과 (글자 단위 나타남) | 실시간 (API 스트림 속도) | - |
| 커서 (▌) | 점멸 (opacity 0↔1) | 800ms 주기 | step-end |
| 진행 중 아이콘 (▸) | 좌우 미세 진동 | 1.5초 주기 | ease-in-out |
| 완료 체크 (✅) | 스케일 0→1.2→1 + 페이드인 | 400ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 진행률 바 | 너비 증가 | 연속 (실시간) | linear |
| 대기 스텝 진행으로 전환 | 페이드인 + 슬라이드 다운 (8px) | 300ms | ease-out |

### 9.3 스트리밍 텍스트 상세

Claude API 스트리밍 응답의 특정 키워드를 감지하여 단계를 전환한다:

```
[파싱 규칙]
1. AI 응답의 JSON 스트림에서 "step" 필드가 변경되면 다음 단계로 전환
2. "detail" 필드의 텍스트를 실시간으로 스트리밍 박스에 타이핑 효과로 표시
3. 스트리밍 박스는 최대 3행까지 표시, 초과 시 위에서 스크롤아웃
4. 각 단계 완료 시 체크 아이콘으로 전환 (300ms 애니메이션)

[스트리밍 박스 내부 예시]
"제27조 건폐율: 제2종일반주거지역 60% 이하..."
→ 200ms 후
"제27조 건폐율: 제2종일반주거지역 60% 이하...
 제28조 용적률: 가중평균 250% 적용 검토..."
→ 300ms 후
"제28조 용적률: 가중평균 250% 적용 검토...
 별표 3 대지 안의 공지 기준 확인..."
```
