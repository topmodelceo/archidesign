> 럭셔리앤 인테리어 · AI 가설계 규모검토 플랫폼
> 작성일: 2026-10-31 · LUXURYN Co., Ltd.

## 1. 서비스 정의

### 1.1 서비스명
- 국문: **신축규모검토** (AI 가설계 규모검토 플랫폼)
- 영문: **ArchiDesign** — AI Building Feasibility Review Platform
- 브랜드: 럭셔리앤 인테리어 (LUXURYN INTERIOR)

### 1.2 서비스 개요
주소(필지)를 입력하면 대한민국 건축법규를 기반으로 해당 토지에 신축 가능한 건물의 최대 규모를 자동 산출하는 AI 규모검토 서비스.

### 1.3 타깃 사용자
| 구분 | 대상 | 주요 니즈 |
|------|------|-----------|
| 1차 | 럭셔리앤 인테리어 고객 | 신축 전 규모 확인, 인테리어 상담 연결 |
| 2차 | 부동산 개발 사업자 | 토지 매입 전 사업성 검토 |
| 3차 | 건축주·일반 사용자 | 내 땅에 얼마나 지을 수 있는지 확인 |

### 1.4 핵심 가치
- **즉시성**: 주소 입력만으로 3초 내 결과
- **정확성**: 16개 용도지역, 10가지 건물 용도별 법규 자동 적용
- **시각성**: 3D 아이소메트릭 건물 매스 + 게이지 차트
- **연결성**: 결과에서 럭셔리앤 인테리어 상담으로 자연스러운 전환

## 2. 핵심 기능

### 2.1 기능 목록

| # | 기능명 | 설명 | 우선순위 |
|---|--------|------|----------|
| F01 | 주소 검색 | 주소 입력 → 자동완성 → 필지 선택 | P0 |
| F02 | 토지 정보 조회 | 선택 필지의 면적·용도지역·지목·도로폭 등 표시 | P0 |
| F03 | 건물 용도 선택 | 10가지 건물 용도 중 선택 | P0 |
| F04 | 규모검토 실행 | 건폐율·용적률·높이제한·일조권·주차 종합 산출 | P0 |
| F05 | 결과 개요 | 3D 매스 + 게이지 차트 + 핵심 수치 카드 | P0 |
| F06 | 법규 검토 | 8개 항목 적합/부적합 판정 + 적용 법규 요약 | P0 |
| F07 | 상세 수치 | 산출표 + 층별 면적 구성안 | P0 |
| F08 | 결과 PDF 저장 | 검토 결과를 PDF로 다운로드 | P1 |
| F09 | 상담 신청 | 럭셔리앤 인테리어 상담 연결 CTA | P1 |
| F10 | 검토 이력 | 최근 검토 이력 저장·재조회 | P2 |

### 2.2 데이터 구조

#### 용도지역 데이터 (ZONE_DATA)
```
16개 용도지역 × 8개 속성:
- 건폐율(%), 용적률(%)
- 높이제한(m, nullable)
- 일조권 적용 여부
- 인접도로 최소폭(m)
- 전면이격거리(m), 측면이격거리(m)
- 표시 색상, 축약 라벨
```

#### 건물 용도 데이터 (BUILDING_USES)
```
10개 건물 용도 × 2개 속성:
- 주차면적기준(㎡/대)
- 조경면적비율(%)
```

#### 필지 데이터 (LOT)
```
- address: 주소
- 지목, 면적(㎡), 용도지역
- 도로폭(m), 대지형상, 경사도(%), 방위
- 지구단위계획 여부
```

#### 산출 결과 (RESULT)
```
- 대지면적, 건축면적, 연면적, 법정연면적
- 건폐율, 용적률, 최종용적률
- 실제층수, 최대층수, 건물높이
- 최대높이, 도로사선높이, 일조권높이
- 주차대수, 주차면적, 조경면적
- 전면/측면 이격거리, 유효가로/세로
```

## 6. 적용 법규

- 국토의 계획 및 이용에 관한 법률 제77조(건폐율), 제78조(용적률)
- 건축법 제58조(대지 안의 공지), 제61조(일조 등의 확보를 위한 건축물의 높이 제한)
- 건축법 시행령 제80조(건축물의 높이 제한), 제86조(일조권)
- 서울특별시 건축조례 제29조~35조(용도지역별 건폐율·용적률)
- 주차장법 시행령 제6조(부설주차장 설치기준)
