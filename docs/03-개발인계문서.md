## 4. 컴포넌트 명세

### 4.1 SLabel — 섹션 라벨

골드 포인트 라인 + 영문 라벨.

| Prop | Type | 설명 |
|------|------|------|
| text | string | 영문 라벨 텍스트 (uppercase) |

```
구조: [6px gold dot][84px gold line][12px gap][label text]
```

### 4.2 Stat — 수치 카드

| Prop | Type | 설명 |
|------|------|------|
| label | string | 영문 라벨 (uppercase, --latin) |
| value | string | 주요 수치 (--mono 700) |
| sub | string? | 부가 정보 (--muted) |
| accent | string? | 수치 색상 (기본: --ink) |

### 4.3 Gauge — 원형 게이지

| Prop | Type | 설명 |
|------|------|------|
| value | number | 현재 값 |
| max | number | 최대 값 (100% 기준) |
| label | string | 라벨 |
| unit | string | 단위 (기본: "%") |
| color | string | 게이지 색상 (기본: --gold) |

### 4.4 RC — 법규 검토 아이템

| Prop | Type | 설명 |
|------|------|------|
| label | string | 검토 항목명 |
| status | "pass" \| "warn" \| "fail" | 판정 |
| detail | string | 세부 설명 |

### 4.5 BViz — 3D 건물 매스

| Prop | Type | 설명 |
|------|------|------|
| result | CalcResult | 산출 결과 객체 |

## 5. API 설계 (Phase 2 개발팀)

### 5.1 주소 검색 API

현재 프로토타입은 12건의 SAMPLE_LOTS 로컬 데이터를 사용합니다.
개발팀에서 아래 API로 전환:

```
GET /api/search?q={주소키워드}

Response:
{
  "results": [
    {
      "address": "서울특별시 강남구 역삼동 123-4",
      "지목": "대",
      "면적": 330.5,
      "용도지역": "제2종일반주거지역",
      "도로폭": 8,
      "대지형상": "정형",
      "경사도": 2,
      "방위": "남향",
      "지구단위": false
    }
  ]
}
```

**연동 가능 외부 API:**
- 브이월드 API (vworld.kr) — 주소 검색, 필지 정보
- 국가공간정보포털 — 토지이용계획
- 토지이용규제정보서비스 — 용도지역 확인
- 세움터 (building.go.kr) — 건축행정 데이터

### 5.2 규모검토 API

현재는 클라이언트 사이드 calcBldg() 함수로 처리.
서버 사이드 전환 시:

```
POST /api/calculate
Body: { "lot": {...}, "use": "다세대주택" }

Response:
{
  "result": {
    "대지면적": 330.5,
    "건축면적": 198.3,
    "연면적": 1189.8,
    ...
  },
  "regulations": [
    { "label": "건폐율 검토", "status": "pass", "detail": "..." },
    ...
  ]
}
```

## 6. 네이티브 앱 가이드

### 6.1 Capacitor 설정

기존 `capacitor.config.ts` 수정 사항:

```typescript
import type { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'com.luxuryn.archidesign',
  appName: '신축규모검토',
  webDir: 'design',  // ← design 폴더의 index.html 사용
  server: { androidScheme: 'https' },
  plugins: {
    SplashScreen: {
      launchShowDuration: 2000,
      backgroundColor: '#FAF9F7',  // ← 밝은 배경으로 변경
      showSpinner: false,
      splashFullScreen: true,
      splashImmersive: true
    },
    StatusBar: {
      style: 'LIGHT',              // ← 밝은 배경이므로 다크 아이콘
      backgroundColor: '#F6F2ED'
    }
  },
  ios: {
    contentInset: 'automatic',
    preferredContentMode: 'mobile',
    scheme: 'ArchiDesign'
  },
  android: {
    backgroundColor: '#FAF9F7'     // ← 밝은 배경으로 변경
  }
};

export default config;
```

### 6.2 아이콘·스플래시 변경 사항

기존 파란-보라 그라데이션 + 建 → **아이보리 배경 + LUXURYN 골드 심볼**로 교체 필요.

- iOS: `ios/App/App/Assets.xcassets/AppIcon.appiconset/`
- Android: `android/app/src/main/res/mipmap-*/`
- 스플래시: #FAF9F7 배경 + LUXURYN INTERIOR 로고 중앙

### 6.3 빌드 순서

```bash
# 1. 의존성 설치
npm install

# 2. design/index.html을 www로 복사 (또는 webDir 변경)
cp design/index.html www/index.html

# 3. Capacitor sync
npx cap sync

# 4. iOS 빌드
npx cap open ios

# 5. Android 빌드
npx cap open android
```
