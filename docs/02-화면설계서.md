## 1. 디자인 시스템 적용

### 1.1 컬러 토큰 (LUXURYN Interior)
```css
:root {
  /* 배경 */
  --bg: #FAF9F7;          /* 메인 배경 (아이보리) */
  --card: #FFFFFF;         /* 카드 배경 */
  --bar: #F6F2ED;          /* 서브 배경, 바 */
  --line: #ECE6DE;         /* 구분선 */

  /* 브랜드 */
  --gold: #A8834F;         /* 주요 악센트 (골드) */
  --gold-lt: #C4A57A;      /* 보조 골드 */
  --gold-line: #C8B091;    /* 골드 라인 */

  /* 텍스트 */
  --ink: #2F2E2C;          /* 제목 텍스트 */
  --text: #3B3A38;         /* 본문 텍스트 */
  --muted: #8A8783;        /* 보조 텍스트 */

  /* 다크 섹션 */
  --dark: #2B2926;         /* 다크 배경 */
  --dark-card: #2F2D2A;    /* 다크 카드 */

  /* 기능 컬러 */
  --pass: #5B8C5A;         /* 적합 (그린) */
  --warn: #C4923E;         /* 주의 (앰버) */
  --fail: #B55454;         /* 부적합 (레드) */
}
```

### 1.2 서체
- 한글: Pretendard (제목 600–700, 본문 400)
- 영문 라벨: Questrial (자간 넓게)
- 로고: Jost 600
- 수치 데이터: JetBrains Mono (기존 유지)

### 1.3 반응형 브레이크포인트
- Desktop: ≥ 1024px → max-width 960px, 2컬럼 그리드
- Tablet: 768–1023px → 1컬럼, padding 32px
- Mobile: < 768px → 1컬럼, padding 16px, 터치 최적화

## 3. 인터랙션 명세

### 3.1 주소 검색
- 2글자 이상 입력 시 자동완성 드롭다운 표시
- 드롭다운: --card 배경, shadow(0 8px 32px rgba(0,0,0,0.08)), 최대 높이 240px 스크롤
- 항목 호버: --bar 배경
- 항목 선택 시 드롭다운 닫힘, 토지 정보 카드 표시

### 3.2 규모검토 실행
- 1.2초 로딩 애니메이션 (골드 스피너)
- 결과 표시 시 fade-in (0.3s ease)
- 기본 탭: 개요

### 3.3 탭 전환
- 전환 시 컨텐츠 fade (0.2s)
- 하단 골드 라인 슬라이드 애니메이션

### 3.4 모바일 터치
- 모든 터치 타겟 최소 44px 높이
- input font-size 16px (iOS 줌 방지)
- 드롭다운 최대 높이 40vh
